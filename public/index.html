📖 API Documentation


    

      
GET /scrape — Free Tier (rate limited)

      
curl "https://url2md.up.railway.app/scrape?url=https://example.com"

    


    

      
GET /scrape — Pro Tier (unlimited)

      
curl "https://url2md.up.railway.app/scrape?url=https://example.com&key=YOUR_API_KEY"

    


    

      
Response

      
{
  "markdown": "# Example Domain\n\nThis domain is for use in illustrative examples...",
  "title": "Example Domain",
  "url": "https://example.com"
}

    


    

      
Rate Limit Headers (free tier)

      
X-RateLimit-Limit: 10
X-RateLimit-Remaining: 9
X-RateLimit-Reset: 1704067200

    


    

      
Error Responses

      
400 { "error": "Invalid URL" }
401 { "error": "Invalid or inactive API key" }
429 { "error": "Rate limit exceeded..." }
502 { "error": "Failed to scrape: ..." }
